# 🚗 AutoVoiture - Car Sales & Appointment System

AutoVoiture is a web-based application built with PHP and MySQL that allows users to browse car listings and schedule appointments to visit the dealership in person.

---

## ✨ Features

- **Car Catalog:** Browse available cars with specifications and details.
- **Appointment Scheduling:** Book a dealership visit (Monday to Saturday, 09:00 - 19:00).
- **Admin Panel:** Manage car listings, view requests, and update vehicle details.
- **Responsive Design:** Optimized for desktop and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3
- **Backend:** PHP (PDO)
- **Database:** MySQL
- **Environment:** XAMPP (Apache & MySQL)

---
